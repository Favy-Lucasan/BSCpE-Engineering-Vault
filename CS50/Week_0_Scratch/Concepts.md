## High-Level Abstractions

* **Computer Programming:** Basically, it is about taking inputs and processing them using algorithms (step-by-step problem solving instructions), and producing meaningful outputs.
* **Binary (Base-2):** It is the system computers use to count. A "bit" (binary digit) represents the most basic form of data which is 0 or 1, which directly corresponds to the physical on or off state of a transistor.
* **Byte:** It is a sequence of 8 bits. It is the standard unit of memory in computing. If all 8 bits of a byte are turned "on" (11111111), it represents the decimal value 255 (128+64+32+16+8+4+2+1).
* **ASCII (American Standard Code for Information Interchange):** A character encoding standard that is used to map binary values to text. Example: the sum of 65 of binaries represents the letter "A" and if we add the number 32, we get its lowercase which is "a". It uses 7 bits to represent 128 characters.
* **UNICODE:** It is an upgraded version of ASCII which supports over a million characters that allows to support of international alphabets and complex symmbols including emojis. 
* **RGB (Red, Green, Blue):** A color model that represents colors by mixing each of their different light intesities. Each channel consists of one byte (8 bits), with an intensity range of 0 to 255.
* **ALGORITHM:** It is a computer's systematic step-by-step procedure to solve a specific problem.
* **PSEUDOCODE:** A plain-English representation of an algorithm's logic. It outlines step-by-step instructions in a structured format optimized for human readability.
* **SCRATCH:** It is a visual programming language developed by MIT.
